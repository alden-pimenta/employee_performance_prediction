# Project Requirements – INX Future Inc. Employee Performance Analysis (IABAC 10281)

Source: `CDS_Project_2_INX_Future_Emp_Data_V1_6.pdf` (in this folder).

## Business context
INX Future Inc. is a data analytics and automation provider rated a top-20 employer for five years. Employee performance indexes have fallen, service-delivery escalations have risen and client satisfaction dropped by 8 percentage points. The CEO does not want to penalise non-performers in a way that hurts the morale of everyone else, and wants clear indicators of non-performing employees.

## Required insights
1. Department-wise performance.
2. Top 3 important factors affecting employee performance.
3. A trained model that predicts employee performance from input factors (to be used when hiring employees).
4. Recommendations to improve employee performance.

## Data
`INX_Future_Inc_Employee_Performance_CDS_Project2_Data_V1_8.xls`: 1200 employees, 28 columns, target `PerformanceRating`. Stored unchanged in `data/raw/`.

## IABAC submission guidelines applied
Jupyter notebooks with Markdown explanations; project summary (algorithm, important features, tools); feature selection and transformation explained; results, insights and recommendations; required folder structure; submission within 7 days of receiving the assignment.
